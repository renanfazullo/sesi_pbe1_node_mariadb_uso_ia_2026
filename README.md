# Registros de Uso de IA

## Descrição

Sistema desenvolvido para registrar e consultar como empresas, escolas e pessoas utilizam Inteligência Artificial, identificando suas finalidades, tecnologias utilizadas e possíveis níveis de risco.

## MER DER Conceitual

![MER DER](docs/der_uso_ia.png)

## Tecnologias Utilizadas

- Node.js
- Express
- MariaDB
- MySQL2
- JavaScript
- Insomnia
- Visual Studio Code
